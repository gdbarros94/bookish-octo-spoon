# ATIVIDADE: Swiss Army Knife App Flutter

## Objetivo
Desenvolver um aplicativo Flutter multifuncional ("canivete suíço") que reúna diversas ferramentas úteis em um só lugar. O app deve ser responsivo, intuitivo, visualmente agradável e funcional tanto para Web quanto para Android.

## Descrição da Atividade
Você deverá criar um aplicativo Flutter chamado "Swiss Army Knife" que contenha, no mínimo, as seguintes categorias de ferramentas:

1. **Conversor de Unidades**
   - Conversão entre diferentes unidades de medida (ex: metros para quilômetros, gramas para quilos, Celsius para Fahrenheit, etc).
2. **Conversor de Medidas**
   - Conversão entre diferentes sistemas de medidas (ex: imperial para métrico, polegadas para centímetros, libras para quilos, etc).
3. **Ferramentas de Texto**
   - Funções como contar caracteres/palavras, inverter texto, transformar para maiúsculas/minúsculas, remover espaços extras, etc.
4. **Calculadora**
   - Calculadora básica (operações aritméticas) e, se possível, científica (potência, raiz, seno, cosseno, etc).
5. **Gerador de Senhas**
   - Geração de senhas seguras, com opções de tamanho, uso de caracteres especiais, números, etc.
6. **Conversor de Moedas**
   - Conversão entre diferentes moedas, utilizando uma API para obter taxas de câmbio atualizadas.
7. **Ferramentas de Data e Hora**
   - Conversor de fusos horários, calculadora de diferença entre datas, cronômetro, temporizador, etc.

## Requisitos Obrigatórios
- O app deve ser desenvolvido em Flutter, utilizando boas práticas de programação, organização de código e design responsivo.
- Cada categoria deve ser acessível por meio de um menu lateral ou barra de navegação clara.
- Cada ferramenta deve ter uma tela própria, com interface amigável e instruções de uso.
- O app deve ser exportado e testado para Web e Android (forneça prints ou vídeos de ambos funcionando).
- O código deve estar bem comentado e organizado em pastas por funcionalidade.
- O README.md deve conter instruções claras de execução, build e exportação para Web e Android.
- O app deve ter uma tela inicial apresentando o propósito do "Swiss Army Knife" e orientando o usuário.
- O design deve ser limpo, moderno e responsivo.
- Não utilize pacotes ou soluções prontas para as funcionalidades principais (ex: não use pacotes de conversão prontos, implemente a lógica).
- Utilize pelo menos 2 widgets personalizados criados por você.
- O app deve ser entregue com o código-fonte completo e pronto para build.

## Entrega
- Data limite: **05/09/2025** (entregas após essa data não serão aceitas)
- Cada aluno deve criar um repositório próprio no GitHub para o projeto.
- O repositório deve conter todo o código-fonte, ATIVIDADE.md, README.md e instruções de build/exportação.
