# ATIVIDADE: Pokedex Temática Flutter

## Objetivo
Desenvolver um aplicativo Flutter que funcione como uma "Pokedex" temática, baseada em um universo de sua escolha (jogo, série, anime, filme, etc). O app deve ser estilizado conforme o tema escolhido e consumir uma API pública gratuita (como TheMovieDB, Bump.sh, IGDB, etc) para buscar e exibir informações de personagens, funcionando como um catálogo interativo.

## Descrição da Atividade
Você deverá criar um aplicativo Flutter chamado "Pokedex Temática" que atenda aos seguintes requisitos:

### Tema
- Escolha um universo de sua preferência (ex: Harry Potter, Star Wars, Marvel, Naruto, League of Legends, etc).
- O design, cores, ícones e fontes do app devem remeter ao tema escolhido, demonstrando personalização e criatividade.

### Funcionalidades Obrigatórias
- Tela inicial apresentando o tema e orientações de uso.
- Tela de busca inteligente: conforme o usuário digita, uma lista de personagens é exibida em tempo real (autocomplete/sugestão).
- Ao selecionar um personagem, exibir uma tela detalhada com as principais informações e imagem do personagem, vindas da API.
- Consumo de uma API pública gratuita (ex: TheMovieDB, Bump.sh, IGDB, etc) para buscar os dados dos personagens. Não é permitido usar listas estáticas ou arquivos locais para os personagens principais.
- O app deve ser responsivo e funcionar em diferentes tamanhos de tela.
- O código deve ser organizado, comentado e separado em arquivos/pastas por funcionalidade.
- O app deve ser exportado e testado para Web e Android (forneça prints ou vídeos de ambos funcionando).
- O README.md deve conter instruções claras de execução, build e exportação para Web e Android.
- Não é permitido usar reconhecimento por câmera ou upload de imagens para busca.
- A busca deve ser textual, com sugestões dinâmicas conforme o usuário digita.
- Utilize pelo menos 2 widgets personalizados criados por você.
- O app deve ser entregue com o código-fonte completo e pronto para build.

### Requisitos Técnicos
- Utilizar Flutter e boas práticas de programação.
- Utilizar uma API pública gratuita para busca dos personagens (ex: TheMovieDB, Bump.sh, IGDB, etc). Justifique a escolha da API no README.md.
- Não utilizar listas estáticas ou arquivos locais para os personagens principais.
- O app deve ser estilizado de acordo com o tema escolhido.
- O código deve estar bem comentado e organizado.
